## Installation sur mac OS
1. Téléchargez le fichier NAMESOFT.dmg
2. Ouvrez le Terminal a l'emplacement du telechargement du DMG
3. Tapez : `xattr -cr "arrera-postite.dmg"
4. Montez le DMG et glissez l'app vers Applications
5. Si macOS bloque encore l'app : Préférences Système > Sécurité > "Ouvrir quand même"
